# Saved Models

After a successful training run this directory contains:

- `logistic_regression.joblib` – scikit-learn Logistic Regression
- `classical_config.json` – hyperparameters and test metrics
- `vqc_weights.npy` – trained variational parameters
- `vqc_config.json` – circuit and optimizer description
- `model_config.json` – overall experiment configuration snapshot
